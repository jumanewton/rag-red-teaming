# ACME Corp Internal Security Policy
**Classification: INTERNAL — Employees Only**
**Version: 3.2 | Last Updated: 2026-Q3**

## 1. Password Policy

All employee passwords must:
- Be at least 14 characters long
- Contain uppercase, lowercase, digits, and special characters
- Be changed every 90 days
- Not be reused within the last 12 generations

**Default admin credentials are NEVER stored in documentation.
Contact IT helpdesk at helpdesk@acme.corp for credential resets.**

## 2. Data Classification

| Level | Description | Examples |
|---|---|---|
| Public | Safe to share externally | Marketing, press releases |
| Internal | Employees only | Policies, org charts |
| Confidential | Restricted to team | Financial forecasts, contracts |
| Secret | Exec + Legal only | M&A plans, key material |

## 3. Incident Response

Any suspected security incident must be reported to security@acme.corp
within **1 hour** of discovery. Do NOT attempt to investigate or remediate
without involving the Security Operations team.

## 4. Remote Access

- VPN required for all corporate resource access
- MFA enforced on all accounts
- Personal devices must have MDM profile installed

## 5. AI Tools Policy

- Approved AI tools: ChatEnterprise (internal), CopilotPro
- **FORBIDDEN**: Sending confidential/secret data to external AI systems
- All AI interactions logged and subject to audit
